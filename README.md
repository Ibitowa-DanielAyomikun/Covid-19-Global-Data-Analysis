# Covid-19-Global-Data-Analysis
Analysis of global COVID-19 cases, deaths and recoveries using SQL and data visualisation.
## Introduction 
The COVID-19 pandemic affected countries across the world, leading to restrictions on movement, economic challenges, social disruptions and several other consequences. 
This project investigate the global distribution and progression of CoviD-19 across different countries and region. It focuses on understanding the trend in reported confirmed cases, deaths and recoveries overtime using SQL and Data Visualisation. 
## Objectives 
  The major objective of this project is to : 
  - Analyse reported COVID-19 cases across different countries.
  - Examine the cumulative growth of confirmed cases over time.
  - Investigate reported deaths across countries.
  - Examine reported recoveries across countries.
  - Compare the reported cases, deaths and recoveries between countries.
  - Identify countries with the highest reported COVID-19 cases and deaths.
  - Explore the global progression of the pandemic over time.
## Research Question 
This project seeks to answer the following questions:
- Which countries recorded the highest number of confirmed COVID-19 cases?
- Which countries recorded the highest number of reported deaths?
- How did confirmed cases grow over time?
- How did reported deaths and recoveries change over time?
- Which countries had the highest reported recovery counts?
- How did the pandemic progress globally?
## Dataset And Data Source 
The dataset used for this project is obtained from the Johns Hopkins University Center for Systems Science and Engineering (JHU CSSE).
Source: (https://github.com/CSSEGISandData/COVID-19)
The dataset contains historical COVID-19 records, including confirmed cases, deaths and recoveries, reported across different countries and regions.

## Limitation
- The dataset contains historical records and is not a source of live COVID-19 statistics.
- Reported figures may differ from actual infections and deaths because of differences in testing, reporting and data collection.
- Recovery records are incomplete for some countries and periods.
